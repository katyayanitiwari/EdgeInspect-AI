## Team
1–3 members, Indian nationals. Student teams: same college + faculty mentor. Only the team leader registers.
One change (team or problem statement) allowed within 15 days of registration.

## Phase 1 deliverables
Source code (GitHub), application/demo, technical report, demonstration video.
Format details: via the challenge form (not on the public page — needs verification).

## Hardware (none mandated, none provided)
Arm Android phone, **Raspberry Pi 5 CPU-only**, Raspberry Pi 5 + AI HAT+ / AI HAT+ 2, or Arm Linux device.
Hailo is **optional**: vision on NPU via HailoRT, Llama via ExecuTorch on the Arm CPU, documented as separate pipelines.

## PS5 — Real-time Industrial Defect Detection & Quality-Control Assistant
Must: detect surface defects/cracks/anomalies, classify type **and severity**, alert operators with actionable
recommendations, log inspections, run in real time at the edge with no cloud.
**Required:** a Llama-family model for the advisory/reasoning part, deployed on-device with **ExecuTorch** as reference runtime.
Optional: OpenCV, Hailo SDK, MVTec AD / **NEU Surface Defect** / KolektorSDD, YOLO / EfficientDet, anomaly detection.

## Judging
No weighted criteria published. Phase 1: report, source code, demo. Phase 2: PoC → live demo + jury Q&A.
One winner per problem statement.
