## EXP-002 ONNX export check (9 Oct 2026)

The fixed-shape FP32 ONNX export was evaluated on the same 270-image test split at 320 px, batch 1, CPU. ONNX measured P 0.6806, R 0.7338, F1 0.7062, mAP50 0.7559 and mAP50-95 0.4208. PyTorch at the same validation settings measured P 0.7118, R 0.7093, F1 0.7105, mAP50 0.7702 and mAP50-95 0.4361. The ONNX result is lower by 0.0143 mAP50 and 0.0152 mAP50-95. ONNX file size was 12.12 MB vs 6.22 MB for the PyTorch checkpoint. A separate 30-image, confidence-0.25 prediction check matched 31 of 31 detections at IoU ≥ 0.50; this limited check does not replace full-test mAP. Keep PyTorch `best.pt` for the dashboard for now. Details: `deployment/EXP-002_ONNX_NOTES.md`, `evaluation/EXP-002/onnx_metrics.json`, `pytorch_batch1_metrics.json`, and `onnx_parity.json`. No Pi or Hailo results are available.
